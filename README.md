# WEGO-MORAI 자율주행 경진대회

MORAI 시뮬레이터 환경에서 LiDAR와 카메라 센서를 활용한 자율주행 알고리즘 구현 프로젝트입니다.  
카메라 기반 차선 추종과 LiDAR 기반 장애물 회피, 회전교차로 진입 판단 로직을 구현했습니다.

## 주요 기능

### 1. LiDAR 기반 동적/정적 장애물 인지 및 회피 주행
자차 이동에 따른 상대 속도 오인식을 방지하고, 장애물 종류에 따라 회피 동작을 분기하도록 구현했습니다.

- **군집화 및 대표 좌표 추출 (Clustering)**
  - 2D LiDAR 스캔 데이터를 차량 전방 기준으로 정렬 및 결측치 처리
  - 유클리디안 거리 기반 클러스터링으로 개별 장애물 분리 및 중심 좌표(x, y) 도출
- **프레임 시간 차분 기반 동적/정적 판별**
  - 전방 위험 영역(2.0m 이내) 진입 시 STOP 상태로 일시정지하여 자차 이동으로 인한 상대 운동 오차 제거
  - 약 1초간 프레임 버퍼를 누적하며 장애물 중심점 이동 거리 및 거리 차분 평균(moving_score) 계산
  - 이동 거리 0.25m 이상은 동적 장애물, 미만은 정적 장애물로 분류
- **상태 머신 기반 회피 제어**
  - 동적 장애물(DYNAMIC_STOP): 주행 경로에서 벗어날 때까지 정지 대기 후 직진 주행 복귀
  - 정적 장애물(AVOIDING): 장애물 위치 및 주변 공간에 따라 조향과 속도 프로파일을 생성해 회피 후 차선 복귀

### 2. 회전교차로 주행 (Roundabout Navigation)
- 교차로 진입 구간에서 좌측 및 내부 회전 차량을 LiDAR 클러스터링으로 탐지하여 진입 타이밍 판단
- 곡률 구간에서 차선 및 장애물 간격을 고려한 조향 유지

### 3. 카메라 기반 차선 인식 보정
- ROI 영역 조도(V 채널)를 지수이동평균(EMA)으로 추적하는 적응형 HSV 필터링 적용
- 정지선 중복 인식 방지를 위한 히스테리시스 로직 적용

## 시스템 구조

```
/lidar2D (LaserScan)
  └─> lidar_node.py (전방 정렬 및 유클리디안 클러스터링)
        └─> /lidar_clusters
              └─> control_node.py (동/정적 판별 및 주행 제어)
                    └─> /ackermann_cmd
```

## 개발 환경

- OS: Ubuntu 20.04 LTS
- Platform: ROS1 Noetic
- Simulator: MORAI Simulator
- Language: Python, C++
